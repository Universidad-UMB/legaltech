# DEC-F4-001 — Decisiones, bloqueos y cambios de contrato

**Estados:** `PR-F4` propuesta técnica; `SA` seleccionada por autores sin ratificación organizacional; `PEND` necesita elección; `PV1` diferido.

| ID | Asunto | Diseño propuesto | Estado | Impacto / acción |
|---|---|---|---|---|
| D-F4-01 | Autenticación | Token bearer opaco, Argon2id, 60 min absolutos, SHA-256 en DB, revocable | PR-F4 | Aceptar TTL y almacenamiento en memoria; seguridad del navegador |
| D-F4-02 | API versionada | `/api/v1`, OpenAPI 3.1.1, JSON, problem+json | PR-F4 | Contratos consumibles por frontend |
| D-F4-03 | 404 de portal | Ocultar ámbito ajeno, suspensión y fin bajo 404 genérico; `200 available=false` si cuenta **sí** tiene alcance y no hay publicación | PR-F4 / SA DEC-03/04 | Verificar que el cliente no infiere recurso ajeno |
| D-F4-04 | Roles | ADMIN, ANALYST, LAWYER, PREPARER, COORDINATOR, EXTERNAL_READER; asignación explícita interna y externa | PR-F4 | Los roles solos no dan acceso; ADMIN sin bypass a separación de personas |
| D-F4-05 | Gestión de usuarios | Sin CRUD de cuentas ni scopes en API demo; seeds locales idempotentes | PR-F4 | No confundir con V1 administración de perfiles |
| D-F4-06 | Idempotencia HTTP | request_key solo para adquisición; comparación/evaluación por unicidad natural; otros POST conflicto de estado | PR-F4 | No inventar tabla genérica `idempotency_keys` |
| D-F4-07 | Publicación | Versión congelada, persona diferente, commit de publicación atómico | PR-F4 / PEND DEC-09 | Salvaguarda DEMO; no aprobar política V1 |
| D-F4-08 | Revisión jurídica | Obligatoria antes de someter comunicación en DEMO | PR-F4 / PEND DEC-08 | No equivale a política final por categoría B1–B6 |
| D-F4-09 | CORS/CSRF | Bearer header sin cookies; allowlist desarrollo explícita; sin CSRF de cookie en contrato actual | PR-F4 | Si se usan cookies, volver a diseñar auth y defensa CSRF |
| D-F4-10 | Publicación textual | Local vía API, sin PDF/correo/webhooks | PR-F4 | Publicación final real PV1 diferida |
| D-F4-11 | Usuarios con privilegio ADMIN | ADMIN puede provisionar clientes/seguimientos; operaciones del caso requieren asignación contextual | PR-F4 | Definir seed de asignaciones; no `superuser` universal |
| D-F4-12 | Orden de observaciones | No perder cambios si `adoptions` adelanta último snapshot antes de evaluar | **PEND** | Diseñar guardas y orden o un único caso de uso de avance; afecta API/F5 y transacciones |
| D-F4-13 | Multiplicidad de seguimiento | DDL propone máximo uno no finalizado por cliente y proceso | **PEND D-F3-03** | Aceptar antes de aplicar índice parcial Alembic |
| D-F4-14 | Sesión / cuenta suspendida | No revocar token por suspender cliente; bloqueo aplica al recurso en cada consulta | PR-F4 / SA DEC-03 | Añadir prueba con sesión expedida antes de suspensión |
| D-F4-15 | Contrato de reintentos | 409 en transiciones duplicadas no idempotentes; 200 en comparaciones/evaluaciones equivalentes | PR-F4 | Frontend debe distinguir conflicto de resultado exitoso |
| D-F4-16 | Asignación de rol de alta de proceso | Por defecto ADMIN; opción ANALYST con política futura | **PEND** | Para demo elegir ADMIN, salvo aceptación explícita de ANALYST |
| D-F4-17 | Retención, proveedor, documento real | Fuera del incremento, sin política productiva por inferencia | PV1 | Revisión jurídica/privacidad posterior |

## Bloqueos antes de entregar al agente

1. Aceptar expresamente alcance, dominio, arquitectura y esquema como **especificaciones del prototipo**, no como políticas V1 ratificadas.
2. Resolver D-F4-12 (adopción/comparación) con diseño preciso para no perder cambios.
3. Resolver D-F4-13 (máximo un seguimiento no finalizado por cliente+proceso).
4. Confirmar las propuestas de revisión jurídica y segregación para **la demo**, DEC-08/09 sin aprobación para V1.
5. Revisar la matriz de permisos interna (ADMIN/ANALYST/COORDINATOR) con seed reproducible.
6. Antes de implementación: convertir DDL candidato en Alembic y probar **durante el desarrollo**, como indicó el equipo. Esto no impide Fase 5 de planificación.

**No son bloqueantes de Fase 5:** CPNU real, SAMAI real, LLM, retención definitiva, PDF o notificaciones productivas.
